# Workout: Tuesday — Cardio (HIIT): Treadmill Intervals

Notes: Target duration ~50–58 min. This is the harder cardio day of the week, but keep the first block controlled so you stay fresh for Wednesday legs. If joints feel beat up, swap to AirBike with the same work/rest structure.

## P1 — Preparation: General Warm-up

### **P1.A**
Treadmill walk/jog — 1×10 min — load incline 1–2%


## P2 — Preparation: Mobility + Activation

### **P2.A**
DopamineO® Band complex exercise — 1×10

### **P2.B** Hip mobility (superset) — sets 1 — rest between 0s / after-set 45s
1) Hip backward “stretch L” — 8 — load BW
2) 90 degree sit — 8 — load BW


## M1 — Main Part: Intervals

### **M1.A**
Running — 6×(90s hard @ RPE 8 + 90s easy) — load incline 2%

### **M1.B**
Running — 2×(4' steady-hard @ RPE 7.5 + 2' easy) — load incline 2%


## C1 — Cool-down

### **C1.A**
Walk / easy spin — 1×8–10 min
